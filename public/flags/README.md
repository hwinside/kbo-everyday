# 국기 SVG 에셋 (출처·라이선스)

이 디렉터리의 국기 SVG(`us/jp/ve/do/au/tw/cu/pr.svg`)는 **flag-icons** 프로젝트의
4x3 원본을 그대로 가져온 것입니다.

- 출처: https://github.com/lipis/flag-icons (`flags/4x3/{code}.svg`)
- 라이선스: MIT License
- 용도: 외국인 선수 국적 표시(`src/components/player/CountryFlag.tsx`).
  이모지 국기(🇺🇸)가 안드로이드·삼성 일부 기기에서 글자로 깨지는 문제를 피하기 위해 SVG로 렌더.
