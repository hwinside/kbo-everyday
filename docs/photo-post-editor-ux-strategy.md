> **작성:** 삼순이 (CSO) | **날짜:** 2026-03-08
> **목표:** "야구 밈을 가장 쉽게 만들 수 있는 곳 = 크보팬"

## 1. 과제 정의

하린아빠 요청 3가지:
1. 경기/선수 태깅 작성 UX — 귀찮지 않게, 자연스럽게
2. 밈 에디터 — 사진 위 텍스트/에셋 오버레이 (인스타 스토리 에디터 급)
3. GIF 생성 — 동영상 → GIF 변환 (모바일에서도 편하게)

## 2. Part A — 게시물 작성 UX

### 2.1 핵심 원칙: "3탭 이내 완료"

태그가 많으면 작성이 귀찮아짐 → **자동 추천 + 원탭 확인** 패턴으로 마찰 최소화

### 2.2 작성 플로우 (Step-by-Step)

```
[FAB ✏️ 탭]
    ↓
┌──────────────────────────────┐
│  Step 1: 미디어 선택          │
│  ┌──┬──┬──┬──┐              │
│  │📸│📸│📸│📸│ ← 갤러리 그리드│
│  └──┴──┴──┴──┘              │
│  최대 10장 · 선택 순서 표시    │
│                              │
│  [다음 →]                    │
└──────────────────────────────┘
    ↓
┌──────────────────────────────┐
│  Step 2: 편집 (밈 에디터)     │ ← 🆕 Part B에서 상세
│  사진 위 텍스트/스티커 편집    │
│                              │
│  [다음 →]                    │
└──────────────────────────────┘
    ↓
┌──────────────────────────────┐
│  Step 3: 정보 입력 (한 화면)  │ ← 핵심!
│                              │
│  ① 한마디 (텍스트 입력)       │
│  ② 경기 연결 (자동 추천)      │
│  ③ 선수 태그 (자동 추천)      │
│  ④ 해시태그 (자동 생성)       │
│                              │
│  [게시하기]                   │
└──────────────────────────────┘
```

### 2.3 경기 태깅 UX — "스마트 추천"

**문제:** 경기 목록을 직접 찾는 건 귀찮다
**해결:** 시간/위치 기반 자동 추천

```
┌──────────────────────────────┐
│  ⚾ 경기 연결                 │
│                              │
│  📍 지금 근처 경기 (GPS 기반)  │ ← 구장 반경 1km 이내면 자동 감지
│  ┌────────────────────────┐  │
│  │ 🏟️ 삼성 vs 한화 · 대전  │◀━│━ 원탭 선택!
│  │    오늘 18:30 · 진행중   │  │
│  └────────────────────────┘  │
│                              │
│  🕐 최근 경기                 │ ← 최근 24시간 이내 경기
│  ┌────────────────────────┐  │
│  │ 두산 vs LG · 잠실 · 어제 │  │
│  │ SSG vs KT · 인천 · 어제  │  │
│  └────────────────────────┘  │
│                              │
│  🔍 직접 검색                 │ ← 날짜/팀 필터
│  ○ 연결 안 함                 │ ← 스킵 가능
└──────────────────────────────┘
```

**자동 추천 로직:**
1. GPS 위치가 구장 반경 1km → 해당 경기 자동 선택 (확인만 하면 됨)
2. GPS 없으면 → "내 팀"의 최근 경기 상위 표시
3. 시간대 가중치: 경기 종료 후 3시간 이내 → 해당 경기 최상단

### 2.4 선수 태깅 UX — "사진 위 핀"

두 가지 방식 제공:

**방식 A: 사진 위 위치 지정 (인스타 방식)**
```
┌──────────────────────────────┐
│  [사진 영역]                  │
│                              │
│     👆 사진을 탭하여           │
│     선수 위치를 지정하세요      │
│                              │
│         📍← 탭한 위치         │
│                              │
│  ┌────────────────────────┐  │
│  │ 🔍 선수 검색...          │  │
│  │ ┌──────────────────┐   │  │
│  │ │ 구자욱 #50 삼성 외야 │  │  │ ← 경기 태깅된 팀 선수 우선
│  │ │ 이대호 #14 삼성 1루  │  │  │
│  │ └──────────────────┘   │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

**방식 B: 간편 태그 (위치 없이 이름만)**
```
┌──────────────────────────────┐
│  👤 선수 태그                 │
│                              │
│  💡 이 경기 출전 선수          │ ← 경기 연결 시 자동 표시!
│  [구자욱] [이대호] [원태인] [+]│
│                              │
│  🔍 직접 검색                 │
│  ○ 태그 안 함                 │
└──────────────────────────────┘
```

**핵심 UX 트릭:**
- 경기를 먼저 연결하면 → 해당 경기 출전 선수 목록을 자동으로 표시
- 원탭으로 선수 태그 완료 (검색 필요 없음!)
- 이게 "경기 → 선수" 순서가 자연스러운 이유

### 2.5 해시태그 UX — "자동 생성 + 추가"

```
┌──────────────────────────────┐
│  #️⃣ 태그                     │
│                              │
│  🤖 자동 추천 (탭하여 추가)    │
│  [#직관] [#삼성라이온즈]      │ ← 경기 태깅 기반 자동 생성
│  [#구자욱] [#대전]            │ ← 선수 태깅 기반 자동 생성
│                              │
│  추가된 태그:                  │
│  [#직관 ✕] [#삼성라이온즈 ✕]  │
│  [#끝내기홈런 ✕]              │ ← 직접 추가한 태그
│                              │
│  [+ 태그 직접 입력]            │
└──────────────────────────────┘
```

**자동 생성 규칙:**
| 조건 | 자동 태그 |
|------|----------|
| 경기 연결됨 | #팀명 #구장명 |
| 선수 태그됨 | #선수명 |
| GPS가 구장 | #직관 |
| 시범경기 기간 | #시범경기 |
| 개막전 날짜 | #개막전 |

## 3. Part B — 밈 에디터 🎨

### 3.1 컨셉: "야구판 짤 공장"

KBO 팬 문화에서 밈은 핵심 바이럴 도구:
- "이대호 짤", "류현진 짤", "양의지 표정 짤" 등이 커뮤니티에서 끊임없이 재생산
- 현재 밈 제작 과정: 사진 저장 → 외부 앱(포토샵/캔바/짤생성기) → 다시 업로드
- **크보팬 안에서 완결**시키면 = 콘텐츠 생산 속도 ↑ + 이탈 ↓ + 워터마크 바이럴

### 3.2 에디터 레이아웃

```
┌──────────────────────────────┐
│  취소              완료       │
├──────────────────────────────┤
│                              │
│  ┌──────────────────────┐   │
│  │                      │   │
│  │   [편집 중인 사진]     │   │
│  │                      │   │
│  │  ┌─────────────┐    │   │
│  │  │ 야 이거 실화? │    │   │ ← 드래그/리사이즈 가능 텍스트
│  │  └─────────────┘    │   │
│  │                      │   │
│  │     🏟️ ← 스티커      │   │ ← 드래그 가능 스티커
│  │                      │   │
│  └──────────────────────┘   │
```

### 3.4 밈 템플릿 (Quick Meme)

자주 쓰는 밈 포맷을 원탭으로 적용:

```
┌──────────────────────────────┐
│  ⚡ 빠른 밈                   │
│                              │
│  ┌──────┐ ┌──────┐ ┌──────┐│
│  │상단  │ │하단  │ │상+하 ││
│  │텍스트│ │텍스트│ │텍스트││ ← 인스타 밈 포맷
│  │      │ │      │ │      ││
│  │      │ │      │ │텍스트││
│  └──────┘ └──────┘ └──────┘│
│  ┌──────┐ ┌──────┐ ┌──────┐│
│  │캡션  │ │vs   │ │직관  ││
│  │바    │ │비교  │ │인증  ││ ← 야구 특화 포맷
│  │      │ │      │ │      ││
│  └──────┘ └──────┘ └──────┘│
└──────────────────────────────┘
```

**야구 특화 템플릿:**
1. **"이게 야구다" 포맷** — 사진 하단에 굵은 텍스트 + 야구공 아이콘
2. **"VS 비교" 포맷** — 두 사진 나란히 + 중앙 VS 마크
3. **"직관 인증" 프레임** — 날짜/구장/팀 정보가 프레임에 자동 삽입
4. **"경기 결과" 카드** — 스코어 + 하이라이트 사진 합성
5. **"선수 카드" 포맷** — 선수 사진 + 스탯 오버레이 (트레이딩 카드 느낌)

## 4. Part C — GIF 생성 🎬

### 4.1 기술 분석: "모바일에서 GIF, 가능한가?"

**결론: 가능합니다. 단, 현명하게 제한해야 합니다.**

#### 기술 스택 옵션

| 방식 | 설명 | 장점 | 단점 | 난이도 |
|------|------|------|------|--------|
| **A. 클라이언트 사이드** | Canvas API + gif.js/FFmpeg.wasm | 서버 비용 0 | 모바일 성능 이슈 (메모리) | 🟡 |
| **B. 서버 사이드** | 동영상 업로드 → FFmpeg → GIF 반환 | 안정적, 고품질 | 서버 비용, 업로드 시간 | 🟡 |
| **C. 하이브리드** | 미리보기는 클라이언트, 최종 변환은 서버 | 최적의 UX | 구현 복잡 | 🔴 |
| **D. WebCodecs API** | 최신 브라우저 네이티브 디코딩 | 고성능, 메모리 효율 | Safari 호환성 이슈 | 🟡 |

#### 추천: **B안 (서버 사이드) + 스마트 제한**

```
동영상 선택 (최대 15초, 50MB)
    ↓
클라이언트: 구간 선택 UI (시작/끝 트림)
    ↓
서버 업로드 (Vercel Serverless 또는 Supabase Edge Function)
    ↓
FFmpeg 변환: 동영상 → GIF (최대 480px, 10fps, 10초)
    ↓
GIF 반환 → 에디터에서 텍스트/스티커 추가
    ↓
최종 GIF 저장 + 게시
```

### 4.3 GIF 구현 시 제한 사항 (서버 부하 관리)

| 제한 | 값 | 이유 |
|------|---|------|
| 원본 동영상 길이 | 최대 30초 | 업로드 용량 |
| GIF 구간 | 최대 10초 | GIF 용량 관리 |
| GIF 해상도 | 최대 480px 가로 | 용량 + 로딩 속도 |
| GIF 프레임레이트 | 10~15fps | 용량 최적화 |
| GIF 최대 용량 | 10MB | Supabase Storage |
| 일일 생성 제한 | 유저당 20개/일 | 서버 부하 관리 |

### 4.4 GIF 서버 아키텍처

```
클라이언트 (Next.js)
    │
    ├── 동영상 업로드 → Supabase Storage (temp/)
    │
    ├── POST /api/gif-create
    │   body: { videoUrl, startSec, endSec, fps, width }
    │
    └── 폴링 or WebSocket으로 결과 대기

서버 (Vercel Serverless or Supabase Edge Function)
    │
    ├── FFmpeg 실행
    │   ffmpeg -ss {start} -t {duration} -i {input}
    │     -vf "fps={fps},scale={width}:-1:flags=lanczos"
    │     -gifflags +transdiff
    │     output.gif
    │
    ├── GIF → Supabase Storage 저장
    │
    └── 결과 URL 반환

대안: Cloudflare Workers + FFmpeg WASM
    → Vercel의 10초 제한 회피, 엣지에서 실행
```

### 4.5 구현 난이도 평가

> **"너무 무리일까요?"에 대한 답: 아닙니다. 단계적으로 가능합니다.**

| 단계 | 내용 | 난이도 | 소요 |
|------|------|--------|------|
| GIF 없이 밈 에디터만 | 사진 + 텍스트/스티커 | 🟡 보통 | 3~5일 |
| + GIF 기본 | 동영상→GIF (서버 변환) | 🟡 보통 | 2~3일 추가 |
| + GIF 편집 | GIF 위 텍스트/스티커 | 🔴 높음 | 3~5일 추가 |
| + 고급 기능 | 속도 조절, 핑퐁, 크롭 | 🟡 보통 | 2일 추가 |

## 6. 기술 구현 핵심 (삼식이 참고)

### 6.1 밈 에디터 기술 스택

```
Canvas API (2D Context)
├── 사진 렌더링: drawImage()
├── 텍스트: fillText() + strokeText() (테두리)
├── 스티커: drawImage() (SVG/PNG 에셋)
├── 인터랙션: touch events → 드래그/리사이즈/회전
└── 내보내기: canvas.toBlob() → 업로드

필요한 라이브러리:
├── fabric.js (또는 konva.js) — Canvas 위 오브젝트 조작
│   - 드래그, 리사이즈, 회전, 그룹
│   - 터치 지원 내장
│   - 1인 라이센스 무료 (MIT)
├── gif.js (또는 gifshot) — 클라이언트 GIF 생성 (경량 옵션)
└── @ffmpeg/ffmpeg — 서버 사이드 GIF 변환
```

**추천: fabric.js**
- 가장 성숙한 Canvas 조작 라이브러리
- 텍스트/이미지/도형 오브젝트를 개별 조작 가능
- 터치 이벤트 (드래그, 핀치줌, 회전) 내장
- 직렬화/역직렬화 지원 (편집 상태 저장/복원)
- Next.js + React에서 사용 용이

## 7. 경쟁 우위 분석

### 밈 에디터가 있는 서비스 vs 크보팬

| 서비스 | 밈 도구 | KBO 특화 | 커뮤니티 연동 |
|--------|---------|---------|-------------|
| 인스타그램 | 스토리 에디터 (고급) | ✕ | △ (DM만) |
| 캔바 | 풀 에디터 (범용) | ✕ | ✕ |
| imgflip | 밈 생성기 (웹) | ✕ | ✕ |
| 짤생성기 앱 | 기본 밈 (앱) | ✕ | ✕ |
| **크보팬** | **밈 에디터 + GIF** | **⭐ KBO 전용 에셋** | **⭐ 피드 직접 게시** |

**차별화 포인트:**
1. 만든 밈을 바로 피드에 게시 (외부 앱 왕복 불필요)
2. KBO 전용 스티커/템플릿 (팀 마크, 야구 아이콘, 밈 텍스트)
3. 경기/선수 태깅과 자연스럽게 연결
4. 팀 컬러 필터 (내 팀 색상 입히기)

## 8. 핵심 요약

> **"밈 생산 비용을 0에 가깝게"**
>
> 1. **작성 UX** — 경기 자동 추천 + 선수 원탭 태그 + 해시태그 자동 생성 → "3탭 완료"
> 2. **밈 에디터** — fabric.js 기반 Canvas 에디터 + KBO 전용 에셋 → "인스타 스토리 급"
> 3. **GIF 생성** — 서버 사이드 FFmpeg + 10초 제한 → "기술적으로 무리 아님, 단계적 접근"
> 4. **KBO 에셋** — 팀 로고, 야구 스티커, 밈 텍스트, 팀 컬러 필터 → "여기서만 가능"
>
> 야구 밈의 생산-유통-소비가 **크보팬 안에서 완결**되면,
> 밈이 곧 바이럴이 되고, 바이럴이 곧 유입이 됩니다.
