# 📸 크보팬 사진 게시판 UX 전략 & 목업

> **작성:** 삼순이 (CSO) | **날짜:** 2026-03-08
> **목표:** "유저들이 매일 와서 사진만 죽어라 스크롤하면서 댓글달고 놀면서 도파민 뿜뿜하는 게시판"

---

## 1. 현재 상태 진단

### 현재 구조 (AS-IS)
```
┌─────────────────────────────┐
│  < 커뮤니티                  │
│  팀 | 선수 | 티켓 | 구장 | 자유  │
│  [일반] [사진]               │
│  최신 | 인기                  │
├─ 16px ─┬───────────┬─ 16px ─┤
│        │  카드 배경  │        │
│  16px  │ ┌───────┐ │  16px  │
│        │ │ 프로필  │ │        │
│        │ │  정보   │ │        │
│        │ ├───────┤ │        │
│        │ │       │ │        │
│        │ │  사진  │ │        │  ← 사진 가로: ~300px
│        │ │       │ │        │     (전체 390px 중 약 77%)
│        │ ├───────┤ │        │
│        │ │ ❤️ 💬  │ │        │
│        │ └───────┘ │        │
│        └───────────┘        │
├─────────────────────────────┤
│  홈  경기  커뮤니티  선수  순위  │
└─────────────────────────────┘
```

### 문제점
1. **사진 가로 활용률 ~77%** — 양쪽 마진(16px×2) + 카드 패딩(16px×2) = 64px 손실
2. **카드형 구조의 시각적 분리감** — 어두운 배경 위 약간 밝은 카드, 경계가 모호
3. **도파민 트리거 부재** — 좋아요/댓글 외 인터랙션 없음
4. **사진 탐색 경로 단일** — 시간순/인기순만, 맥락 기반 탐색 불가

## 2. 디자인 원칙 (Design Principles)

| 원칙 | 설명 |
|------|------|
| **📐 콘텐츠 맥시멈** | 사진이 주인공. UI 크롬 최소화, 사진 가로폭 100% |
| **⚾ 야구 맥락 내재** | 단순 사진이 아닌 "어느 경기, 어느 선수, 어느 순간"의 맥락 |
| **🔄 도파민 루프** | 스크롤→발견→반응→공유의 순환, 매 3~5초마다 보상 |
| **🏷️ 연결의 그물** | 사진 하나가 선수·경기·태그·유저로 이어지는 탐색 네트워크 |
| **✨ 크보팬만의 맛** | 인스타 클론 ✕, KBO 팬 문화에 특화된 고유한 경험 |

## 4. 🆕 차별화 기능 (KBO-Only Features)

### 4.1 ⚾ 선수 태깅 (Player Tag)

**컨셉:** 사진 속 특정 위치에 선수를 태그. 탭하면 선수 프로필로 이동.

```
┌─────────────────────────────┐
│█████████████████████████████│
│███████ [사진 영역] █████████│
│█████████████████████████████│
│████ ┌──────────┐ ██████████│
│████ │ 📍 이대호  │ ██████████│ ← 태그 말풍선
│████ │  #14 · 1루수 │ ████████│    (사진 위 오버레이)
│████ │  [프로필 보기 →] │ ████│
│████ └──────────┘ ██████████│
│█████████████████████████████│
└─────────────────────────────┘
```

**동작:**
1. 사진 탭 → 태그 아이콘(●) 표시
2. 태그 아이콘 탭 → 말풍선 확장 (선수명 + 등번호 + 포지션)
3. "프로필 보기" 탭 → 선수 프로필 페이지 이동
4. **작성 시:** 사진 업로드 → "선수 태그" 버튼 → 사진 위 위치 지정 → 선수 검색/선택

**도파민 포인트:**
- "이 사진에 누가 있지?" → 탭해서 확인하는 재미
- 선수 페이지에서 "이 선수가 태그된 사진" 역방향 탐색
- 팬들이 직관 사진에 선수 태그하며 자랑하는 문화

---

### 4.2 🏟️ 경기 태깅 (Game Tag)

**컨셉:** 사진에 관련 경기 정보를 연결. 어느 날, 어느 구장, 어느 경기인지 맥락 부여.

```
┌─────────────────────────────┐
│  🌱 하린아빠 루키  ·  3시간 전│
│  ┌─────────────────────────┐│
│  │ ⚾ 삼성 5 : 3 한화       ││ ← 경기 태그 배너
│  │ 3/6(목) 시범경기 · 대전  ││    (탭 → 경기 상세 페이지)
│  └─────────────────────────┘│
├─────────────────────────────┤
│█████████ [사진] ████████████│
```

**동작:**
1. 사진 업로드 시 "경기 연결" → 최근 경기 목록에서 선택 (자동 추천)
2. 피드에서 경기 배너 탭 → 해당 경기 상세 페이지 이동
3. 경기 상세 페이지에서 "이 경기의 사진" 갤러리 제공

**도파민 포인트:**
- 경기 끝나고 직관 사진 올리며 그 경기 추억 기록
- 시간이 지나도 "그 경기" 단위로 사진 모아보기
- 빅매치/역전승 경기 사진이 자연스럽게 몰려 밀도 형성

### 4.4 진입 경로 설계 (Information Architecture)

현재 앱 구조를 유지하면서 태그 탐색으로의 자연스러운 진입 경로:

```
진입경로 1: 헤더 검색 아이콘 (🔍)
  커뮤니티 헤더 우측 검색 아이콘 탭
  → 통합 검색 (태그 / 선수 / 유저 / 게시글)
  → 검색어 입력 시 자동완성: #직관, 이대호, @하린아빠...

진입경로 2: 피드 내 해시태그 탭
  게시글 본문의 #직관 탭
  → 해당 태그 피드 페이지 (3컬럼 그리드)

진입경로 3: 선수 태그 → 선수 프로필 → "태그된 사진" 탭
  사진 속 선수 태그 탭 → 선수 프로필
  → 프로필 내 "📸 태그된 사진" 탭 (신규)

진입경로 4: 경기 태그 → 경기 상세 → "이 경기 사진" 섹션
  경기 배너 탭 → 경기 상세 페이지
  → 하단 "📸 팬 사진" 갤러리

진입경로 5: 커뮤니티 > 사진 탭 상단에 "탐색" 서브탭 추가
  [일반] [사진] → [일반] [사진] [탐색]
  탐색 탭 = 인기 태그 + 구장별 + 3컬럼 그리드 Explore
```

#### IA 맵 (간소화)

```
하단 탭 바
├── 홈
├── 경기
│   └── 경기 상세
│       └── 📸 팬 사진 갤러리 ← NEW
├── 커뮤니티
│   ├── 팀 / 선수 / 티켓 / 구장 / 자유
│   │   ├── 일반 (텍스트 피드)
│   │   ├── 사진 (풀블리드 피드) ← REDESIGN
│   │   └── 탐색 (태그 Explore) ← NEW
│   └── 🔍 검색 (헤더) ← NEW
│       ├── 해시태그 검색
│       ├── 선수 검색
│       └── 유저 검색
├── 선수
│   └── 선수 프로필
│       └── 📸 태그된 사진 탭 ← NEW
└── 순위
```

## 5. 🔥 도파민 루프 설계 (Engagement Loop)

### 5.1 마이크로 도파민 트리거

| 트리거 | 설명 | 주기 |
|--------|------|------|
| **풀블리드 사진** | 스크롤할 때마다 눈에 꽉 차는 사진 | 매 스크롤 |
| **선수 태그 발견** | "어 이 사진에 태그가 있네?" 탭해보는 재미 | 3~5게시물마다 |
| **경기 맥락** | "아 이게 그 역전승 경기 때 사진이구나" | 매 게시물 |
| **좋아요 애니메이션** | 더블탭 시 ❤️ 뿅 애니메이션 (인스타 방식) | 좋아요 시 |
| **댓글 미리보기** | 재밌는 댓글 1개가 피드에 노출 → "더 보고 싶다" | 매 게시물 |
| **해시태그 탐색** | 태그 탭 → 새로운 사진 발견 → 다시 피드 | 탐색 시 |

### 5.2 세션 연장 메커니즘

```
스크롤 피드 (3~5초/게시물)
    ↓
선수 태그 발견 → 탭 → 선수 프로필 (30초)
    ↓
"이 선수 태그된 사진 더 보기" → 새로운 피드 (2~3분)
    ↓
해시태그 발견 (#역전승) → 태그 피드 (2~3분)
    ↓
메인 피드로 복귀 → 계속 스크롤
    ↓
평균 세션 타임: 8~15분 목표 (현재 추정 2~3분)
```

## 6. 크보팬만의 차별화 포인트 (vs 인스타)

| 요소 | 인스타그램 | 크보팬 사진 게시판 |
|------|-----------|-------------------|
| 태깅 | 사람(유저) 태깅 | **선수 태깅** → 선수 DB 연동 |
| 맥락 | 위치 태그 | **경기 태깅** → 경기 데이터 연동 |
| 탐색 | 범용 해시태그 | **KBO 특화 태그** (팀/구장/상황) |
| 피드 | 알고리즘 피드 | **팀별 필터 피드** (내 팀 사진만) |
| 반응 | 좋아요/댓글 | 좋아요/댓글 + **🔥 화력 반응** (팀별 응원 이모지) |
| 갤러리 | 유저 프로필 갤러리 | **경기별 갤러리** + 선수별 갤러리 |
| 콘텐츠 | 범용 사진 | **직관 사진에 최적화** (구장/좌석/응원/선수) |

### 6.1 🔥 화력 반응 시스템 (크보팬 전용)

좋아요 외에 팀별 응원 이모지 반응:

```
┌─────────────────────────────┐
│  ❤️ 42  💬 7                 │
│                              │
│  😤🔥 화력 반응 (길게 눌러 선택) │
│  ┌──┬──┬──┬──┬──┐          │
│  │🦁│🦅│⚡│🐻│🐯│          │ ← 팀별 마스코트 이모지
│  │삼성│한화│SSG│두산│KIA│     │
│  ├──┼──┼──┼──┼──┤          │
│  │🦖│🎵│🐘│🦩│🐐│          │
│  │NC│키움│롯데│LG│KT│       │
│  └──┴──┴──┴──┴──┘          │
│                              │
│  또는 범용: 🔥 ⚾ 👏 😱 🏆   │
└─────────────────────────────┘
```

**동작:**
- 짧게 탭 = ❤️ 좋아요
- 길게 누르기 = 반응 이모지 팔레트 (팀 마스코트 + 범용)
- 게시물 하단에 반응 집계: "🦁 23 🔥 15 ⚾ 8"
- **팀 자존심 자극** → "우리 팀 이모지 더 눌러야지!" → 인게이지먼트 ↑

## 10. 핵심 요약

> **"인스타 + KBO DNA = 크보팬 사진 게시판"**
>
> 1. **풀 블리드** — 사진이 화면을 채운다 (Phase 1, 즉시)
> 2. **선수 태깅** — 사진 속 선수를 탭해서 프로필로 (Phase 3)
> 3. **경기 태깅** — 모든 사진에 "어느 경기"의 맥락을 (Phase 2)
> 4. **해시태그 + 탐색** — KBO 맥락으로 사진을 찾고 발견하는 재미 (Phase 2)
> 5. **화력 반응** — 팀 자존심을 건 이모지 전쟁 (Phase 3)
>
> 이 다섯 가지가 합쳐지면, 인스타를 베꼈다는 느낌 없이
> **"야구팬이라면 여기서 사진 올려야지"** 라는 고유한 포지셔닝이 만들어집니다.
