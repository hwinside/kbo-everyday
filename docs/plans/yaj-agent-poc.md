# 야잘알봇 근본 개선 — 순차 실행

2026-09-28 하린아빠 `123 순차적으로 착수` 범위.

## 1. 국제대회 검색 PoC

- 운영 라우터를 바꾸지 않는 CLI 실험부터 시작한다. 사용자 DM/질문 원장/DB 쓰기 없음.
- 직전 대화와 기준 시각을 모델에 전달하고 모델이 뉴스·위키·공식 규정 검색을 선택한다.
- 최대 3회 검색, 제한 시간 및 결과 크기 상한. 검색 오류와 정상 0건을 구분한다.
- 뉴스는 구단명 유무와 무관하게 기존 10구단 기사 전체를 검색한다. 기사 존재는 질문에 답할 근거 존재를 뜻하지 않는다.
- 국제대회 일정 API는 현재 미연결이다. KBO 일정으로 대체하지 않는다. 근거 없으면 구체적인 부족 정보를 반환한다.
- 답변에는 검색으로 받은 출처 ID 및 원문 인용을 결속한다. 인용 문자열 일치는 의미적 정답 검증이 아니며 독립 평가가 필요하다.
- 운영 공개/기존 경로 교체는 PoC 평가 후 별도 변경이다.

## 2. 최신성 파이프라인

- 나무위키 기존 수집·적재 분리를 유지한다. 허용된 수집 경로와 사이트 정책을 확인한다.
- 변경 문서 선별 → 수집 → 기존 신원 검증 → 임베딩/완전 스냅샷 활성화를 연결한다.
- 마지막 시도·성공 수집·활성 리비전·검색 가능 여부를 별도 관측한다.
- 차단을 네트워크/브라우저 변경으로 우회하지 않는다. 기존 수집 경로가 차단되면 HOLD한다.
- 기존 스케줄과 중복하지 않으며 `.github/workflows/*` 변경·push는 별도 명시 승인 범위다.

## 3. 평가 체계

- 삼식이 평가셋 구성 및 독립 판정 담당. 실패 원장 132건과 국제대회 25턴은 중복·QA 여부 대조 후 사용한다.
- 대화 단위 분리 및 holdout 유지. 동일 기준시각·자료 스냅샷으로 기존/신규 비교한다.
- 요청 일치·문맥 유지·근거 정확성·최신성·적절한 보류를 각각 평가한다.
- LLM 채점만으로 GO하지 않는다. 공식 원문 대조와 독립 수동 판정, 기존 성공 사례 회귀를 포함한다.
- 검색 시도/근거 충분/정답을 분리하며 비용·p50/p95 지연도 보고한다.
