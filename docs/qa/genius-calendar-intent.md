## 검증 구분

작성자는 타입/diff 검사를 수행한다. QA 실행과 판정은 삼식 담당이다.
추가한 스모크는 수치 없는 되묻기의 통과와 수치 후보 유출 차단만 검증한다.
기존 validator도 이 스모크를 통과할 수 있다. 모델이 실제로 되묻는다는 근거나 base 대비 RED가 아니다.
프롬프트 문자열 포함 단언으로 효과를 대신 증명하지 않는다.

## 실행

1. `npm run qa:baseball-official-rag` — 새 되묻기 경계와 기존 명시 연도·현재·연도 미상 계약 회귀.
2. #1656의 독립 실행기 `scripts/qa/genius-opening-evidence.ts`(진단 exact `1979c4947ad04e6d3cefa00b9502c104cd49b362`)와 동일한 모델·시계·코퍼스·연결 조건으로 base/head paired 실행. 실행기는 이 PR에 중복 복사하지 않는다.
3. 아래 질문을 각 3회, reduced/connected 두 조건에서 실행한다. 총 base 48행 + head 48행. 실제 사용한 실행기 SHA와 입력 조건, 검색 순서·선택된 chunk, 모델 원문·calendarClaims·최종 경로·답변을 원장에 보존한다.

| 질문 | head 기대 |
| --- | --- |
| 개막전 언제야? | 대상 시즌 되묻기, 날짜/연도 추정 없음 |
| KBO 개막 날짜 알려줘 | 대상 시즌 되묻기, 날짜/연도 추정 없음 |

| 2026년 KBO 정규시즌 개막일 | 시즌 되묻기 금지. 사건 근거 없으면 기존 HOLD 유지 |
| 2025년 KBO 정규시즌 개막일 | 검증된 동일 연도 근거 또는 기존 HOLD, 2026 대체 금지 |

일부 질문이 공식 RAG에 도달하지 않으면 도달률과 실제 경로를 별도로 보고한다. reduced 성공을 connected 성공으로 확대하지 않는다. 되묻기 대신 INSUFFICIENT로 끝나거나 연도 없는 질문에 과거/현재 날짜를 답하면 목표 미달이다. GENERAL의 한글 날짜 추정도 실패다(숫자 가드만으로 막힌다고 주장하지 않는다).

## 한계와 후속

- 의미 판정은 모델이 수행한다. 코드가 모든 생략·날짜 주장의 의미를 강제로 검증하는 변경은 아니다.
- 직전 사용자 질문의 명시 연도가 이어지는 후속, 단독 연도 답변으로 이어지는 2턴 복구는 추가 관측 대상이며 완료 주장하지 않는다. 이전 봇 답변은 사실 근거로 쓰지 않는다.
- 운영 적재, 검색 선택 개선, 운영 UI→DM/저장 일치, 자연사용 효과는 미검증이다.
- 독립 paired에서 개선이 입증되기 전 Draft 유지. 모델이 기존 근거를 정확히 답하는 경로를 되묻기로 바꾸면 NO-GO.
- 롤백은 해당 프롬프트 변경을 revert하는 별도 PR. DB rollback은 없다.
