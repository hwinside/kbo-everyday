# 국제대회 에이전트 PoC

운영 미연결 실험. 질문 원장·DM·DB 수정 없음. 모델/임베딩 호출 비용은 발생한다.

보호된 실행 환경에서 `GEMINI_API_KEY`, `NEXT_PUBLIC_SUPABASE_URL`,
`SUPABASE_SERVICE_ROLE_KEY`를 주입한 뒤 실행한다. 키를 명령 인자나 출력에 넣지 않는다.

```
npx tsx scripts/baseball-qa/agent/run-poc.ts /protected/anonymized-input.json --read-only > /protected/result.json
```

입력:

```
{"question":"그럼 야구는 언제야?","now":"2026-09-28T05:00:00Z","history":[{"question":"아시안게임 알려줘","answer":"일정을 확인해 볼게요."}]}
```

- 최대 모델 4회·검색 3회·총 45초. 모델 기본값은 현재 답변 모델과 동일하며 `YAJ_POC_MODEL`로 비교할 수 있다.
- 모델이 검색 소스·검색어를 결정하고 결과를 보고 다음 검색 또는 답변/보류를 선택한다.
- 뉴스: 기존 vector RPC를 10구단 전체 범위로 호출. 구단명 필요 없음. 발행 시각 상한을 결과에 적용한다.
- 공식 규정: 기존 임계 0.42 vector RPC. KBO 자료를 국제대회 규정으로 해석하지 않도록 프롬프트에 명시한다.
- 위키: 기존 서빙 뷰의 문서 제목 검색(최대 3개 검색어×6행). 전역 의미 검색이 아니며 긴 문서 후반 근거 누락 가능성이 있다. 이 제한을 품질 성공으로 숨기지 않는다.
- 기사 원문 크롤·일정 API는 없다. 현재 확보된 기사 발췌/문서만 사용한다.
- `answered`는 인용 형식 통과일 뿐 정답/PASS가 아니다. 인용이 문장을 실제 함의하는지 삼식 독립 판정 필수.
- 과거 now를 지정해도 당시 코퍼스를 복원하지 않는다. 공정한 A/B는 같은 자료 스냅샷에서 실행해야 한다.
- 출력에는 근거 전문과 질의가 포함된다. 비식별 입력만 사용하고 결과 파일을 공개하지 않는다.

독립 실행 요청 게이트:

```
npx tsx scripts/qa/genius-agent-poc.ts
```

이 게이트는 검색예산·잘못된 도구·오류/0건 구분·인용 ID/원문 결속을 검증한다.
실제 모델의 도구 선택·자료 충분성·정답·기존 성공 사례 회귀는 별도 평가한다.
