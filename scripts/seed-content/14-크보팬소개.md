# 크보팬에 오신 걸 환영합니다! 👋

안녕하세요! **크보팬**에 오신 것을 환영합니다 🎉

크보팬은 KBO 야구를 사랑하는 팬들이 모여 함께 즐기는 커뮤니티입니다.

## 🏟️ 크보팬에서 할 수 있는 것

### ⚾ 내 팀 게시판
10개 구단별 게시판에서 같은 팀 팬들과 소통하세요. 경기 전망, 선수 이야기, 직관 후기 뭐든 OK!

### 👤 선수 게시판
최애 선수의 TMI, 응원가, 에피소드를 모으는 공간. 덕질은 여기서!

### 💬 경기 실시간 채팅
경기 중에 실시간으로 함께 응원하고, 반응하고, 소통하세요.

### 🎯 승부예측
경기 결과를 예측하고 포인트를 모으세요. 적중률 높은 예측왕은 누구?

### 📝 자유게시판
팀 상관없이 야구 이야기 자유롭게! 토론, 투표, 잡담 모두 환영.

## 🤝 커뮤니티 규칙

1. **서로 존중해주세요** — 다른 팀 팬도 같은 야구팬입니다
2. **스포일러 주의** — 경기 결과 스포는 해당 게시판에서
3. **건전한 토론** — 열정은 좋지만 비방/욕설은 NO
4. **즐겁게!** — 야구는 즐거워야 합니다 😊
