# 팬 에디터 시스템 — "팬이 만들어가는 선수 프로필"

> 상태: Phase 2 (DAU 1,000+ 시 착수)
> 작성: 2026-03-05

## 핵심 컨셉
- 크보팬의 데이터 해자(moat) = 팬이 직접 채워가는 683명 선수 프로필
- 크롤링 의존 탈피 → 팬 생성 콘텐츠(Fan-Generated Content)
- "내가 이 선수 프로필에 기여했다" = 참여감 + 리텐션

## 3단계 권한 시스템

### Level 1: 수정 제안 (모든 로그인 유저)
- 선수 프로필 "✏️ 수정 제안" 버튼
- diff 형태 제출 (섹션 선택 → 수정 내용 입력)
- 제출 즉시 리뷰 큐에 등록
- 채택 시 기여 뱃지 획득

### Level 2: 에디터 (신뢰도 확보 유저)
- 승격 조건: 가입 30일 + 게시글 30개 + 채택된 수정 5건
- 직접 수정안 작성 가능 (리뷰 필요)
- 전용 뱃지: 📝 에디터
- 에디터 전용 기능: 섹션별 편집, 출처 첨부

### Level 3: 리뷰어 (에디터 상위)
- 승격 조건: 채택 20건 이상 + 반려율 10% 미만
- 수정안 승인/반려 권한
- 리뷰어 2명 이상 승인 = 확정
- 전용 뱃지: ✅ 리뷰어

## 수정 프로세스
1. 유저가 수정 제안 or 에디터가 수정안 작성
2. diff 화면: 이전/이후 비교
3. 리뷰어 2명 이상 승인 → 프로필 반영
4. 반려 시 사유 기재 → 제안자에게 알림
5. 수정 히스토리 전체 공개 (투명성)

## 제재 시스템
- 허위/악의적 수정: 1차 경고 → 2차 에디터 30일 정지 → 3차 영구 제한
- 욕설/비방/부적절 내용: 즉시 반려 + 경고
- 본인인증 없이 운영 (Google OAuth 계정 식별 충분)
- DAU 5,000+ 시 본인인증(PASS) 도입 검토 (반복 가입 방지)

## 뱃지 체계
- 🌱 첫 기여: 수정 제안 1건 채택
- 📝 에디터: Level 2 승격
- ✅ 리뷰어: Level 3 승격
- 🏆 프로필 마스터: 채택 50건 이상
- ⭐ 팀 전문가: 특정 팀 선수 20명 이상 기여

## 착수 시점
- DAU 1,000+ (정규시즌 중반 예상)
- 그 전까지는 피드백 시스템(현재)으로 수동 처리
- 에디터 후보 = 활발한 기존 유저 중 자연 선발

## 기대 효과
- 프로필 품질 ↑ (시간 지날수록 자동 개선)
- 팬 참여감 ↑ (내가 기여한 프로필)
- 리텐션 ↑ (에디터/리뷰어 = 이탈률 최저)
- 경쟁 해자 (팬 생성 데이터는 복제 불가)

## 🏟️ 오늘의 경기 한줄 요약 (Fan Game Summary)

### 컨셉
- 경기 종료 후 각 팀 팬이 "한줄 요약" 제출
- 팀별 투표 → 팀 대표 한줄 요약 선정
- 승리팀/패배팀 양쪽 시선이 경기 기록으로 영구 보존
- "같은 경기, 다른 시선" = 크보팬만의 경기 히스토리

### 프로세스
1. 경기 종료 → 24시간 동안 한줄 요약 접수 (140자 제한)
2. 해당 팀 팬만 자기 팀 측 요약에 투표 가능
3. 팀별 최다 투표 = 대표 요약 확정
4. 경기 상세 페이지에 양팀 대표 요약 영구 표시

### 예시
```
2026.04.05 잠실 | LG 5 - 3 삼성

🔵 LG팬 한줄: "치리노스 7회 역전 쓰리런, 잠실이 진동했다 🔥"
🔴 삼성팬 한줄: "8회까지 리드하다 불펜 붕괴... 감독님 왜요 😭"
```

### 장기 가치
- 시즌 종료 시 "2026 크보팬이 기록한 명장면 TOP 10"
- 연도별 아카이브 → 팬 시점의 KBO 역사
- 수년 쌓이면 크보팬만의 독보적 콘텐츠 자산
- 공식 기록에는 없는 "팬의 감정이 담긴 기록"

### 착수 시점
- Phase 2 (DAU 1,000+)
- 팬 에디터 시스템과 동시 or 직후 론칭
