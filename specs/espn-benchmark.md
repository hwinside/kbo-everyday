# ESPN 벤치마킹 + 커뮤니티 결합 스펙

## 개요
ESPN 앱의 데이터 밀도 + 크보 에브리데이의 커뮤니티를 결합하여
"데이터로 싸우는 팬 커뮤니티" 구현

## Phase 1: 경기 UX 강화 (즉시)

### 1-1. 경기 리스트 — 날짜 탭
- 가로 스크롤 날짜 선택 (ESPN 스타일)
- 오늘 중앙 배치, 좌우 ±7일
- 날짜 변경 시 해당일 경기 표시
- 컴팩트 카드: away/home 세로 스택, 점수, 상태 뱃지

### 1-2. 경기 상세 — 팀 비교 바
- 주요 스탯 비교 (H, HR, BB, SO, LOB, TB)
- 팀 컬러 양방향 바 (ESPN 스타일)
- 경기 요약 섹션에 배치

### 1-3. 경기 상세 — WIN/LOSS/SAVE 투수
- 이닝 스코어보드 아래
- 승리/패전/세이브 투수 + 사진 + 기록

### 1-4. 구장 정보 섹션
- 구장명, 위치, 관중수, 경기시간
- 심판 정보
- 구장 기본 정보 (수용인원, 개장년도 등)

## Phase 2: 분란 유도 커뮤니티 (1주 내)

### 2-1. 경기별 라이브 채팅
- 경기 상세 하단 "팬 토론" 탭
- 팀 배지 표시 → 적팀 팬 vs 홈팀 팬 구도
- 핫 코멘트 자동 하이라이트

### 2-2. 논쟁 투표
- "오늘의 MVP는?" (경기 종료 후)
- "감독 교체 찬반" (연패 시 자동 생성)
- "최악의 판정" (논란 경기)
- 투표 결과 팀별 분포 공개 → 분란 극대화

### 2-3. 구장별 커뮤니티
- /stadiums/{stadiumId} 페이지
- 맛집 리뷰 / 좌석 후기 / 주차 정보
- 직관 인증 게시판
- **광고 연동 포인트**: 구장 주변 맛집, 숙소, 교통

## Phase 3: 수익화 연결

### 3-1. 구장 맛집 광고
- 구장별 맛집 리스트 (위치 기반)
- 제휴 광고 / 쿠폰 시스템
- 직관 전 "오늘 뭐 먹지?" 추천

### 3-2. 예측 포인트 상점
- 승부예측 포인트로 굿즈 교환
- 팬 등급 시스템 + 특별 뱃지
