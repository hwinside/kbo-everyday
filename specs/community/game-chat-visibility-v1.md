# 경기 전체 채팅 표시 ON/OFF v1

## 목표

- 경기 중계에 집중하려는 사용자가 전체 채팅을 즉시 숨기고 다시 켤 수 있다.
- OFF 상태에서는 채팅 DOM을 렌더하지 않아 composer focus, 자동 스크롤, hash/deep-link target이 존재하지 않는다.
- 로그인 사용자는 계정 단위, 비로그인 사용자는 현재 기기 단위로 설정을 유지한다.

## UI

- 확정 목업대로 경기 상세 채팅 영역 우측 상단에 `채팅 끄기` 버튼을 둔다.
- OFF 상태에서는 동일 위치에 `채팅 켜기`만 남기고 메시지·분위기·입력창은 모두 숨긴다.

## 실패 정책

- 로그인 사용자의 설정 조회가 끝나기 전이나 조회에 실패하면 채팅을 fail-closed로 숨긴다.
- 저장 실패 시 직전 상태로 롤백한다.

## 검증

- ON만 채팅 렌더 허용, OFF/loading/error는 모두 렌더 금지.
- 로그인 계정 PUT/GET 왕복 및 비로그인 localStorage 유지.
- 모바일 화면에서 OFF 후 채팅 입력창이 focus 대상에 없고, ON 후 다시 표시되는지 확인.
