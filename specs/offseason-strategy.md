# 크보 에브리데이 — 오프시즌 전략

> "시즌 중에만 살아있는 앱은 6개월짜리 앱이다"

## 1. 현실 인식: 오프시즌은 진짜 비수기인가?

### KBO 캘린더
| 구간 | 기간 | 특성 |
|------|------|------|
| 정규시즌 | 3월 말 ~ 10월 초 | ⚾ 풀 트래픽 |
| 포스트시즌 | 10월 중순 ~ 11월 초 | 🔥 피크 트래픽 |
| **스토브리그** | **11월 ~ 1월** | **📰 FA/트레이드/외인 뉴스** |
| **스프링캠프** | **2월 ~ 3월 초** | **👀 기대감 상승기** |
| 시범경기 | 3월 초 ~ 중순 | 📈 복귀 트래픽 |

**핵심**: 순수 "죽은 기간"은 12월~1월 약 2개월. 나머지는 콘텐츠가 존재한다.

---

## 2. 전략 옵션 비교

### Option A: "깔끔하게 쉬기" (최소 운영)
- 비용 0, 리소스 절약
- 리스크: 6개월 걸려 만든 습관 리셋, 앱 삭제, 경쟁자 진입

### Option B: "슬로우 시즌" ⭐ 추천
- 주 1~2시간 + 자동화
- 존재감 유지하면서 지치지 않게

### Option C: "풀 시즌"
- 시즌 중 30~50% 리소스
- ROI 불확실, 1인 개발엔 과부하

---

## 3. Option B 상세 플레이북

### 3-1. 스토브리그 (11~1월) — "이적시장의 열기"

**자동화 콘텐츠**
- 뉴스 크롤러 키워드만 변경: "KBO FA", "트레이드", "외국인 선수"
- 빈도: 1일 2회 (오전/오후), 비용 ≈ 0

**Prediction 시스템 재활용** (핵심 전략)
| 콘텐츠 | 형태 | 개발비용 | 효과 |
|--------|------|----------|------|
| FA 행선지 예측 | "김하성 어디?" 투표 | 낮음 | 🔥🔥 |
| 내년 순위 예측 | 10팀 드래그 정렬 | 중간 | 🔥🔥 |
| 올해의 선수 | MVP/신인왕 팬투표 | 낮음 | 🔥 |
| 이적 평가 | FA 계약 A~F 등급 | 낮음 | 🔥 |
| 드래프트 1픽 | 라운드별 예측 | 낮음 | 중간 |

**포인트가 연결고리**: 시즌 중 쌓은 포인트/등급이 오프시즌에도 유효 → 이탈 방지

### 3-2. 시즌 회고 (11~12월) — "Wrapped"

**스포티파이 Wrapped 컨셉의 "나의 시즌 리포트"**
```
📊 자동 생성:
- "올해 127경기 체크, 352번 예측 참여"
- "당신은 상위 12% 예언가"
- "가장 많이 응원한 선수: 오스틴 (47회)"
- 팀별 시즌 리포트 카드 (A~F)
```

공유 가능한 카드 이미지 → 인스타/트위터 바이럴
**한번 만들면 매년 자동 생성** (ROI 최고)

### 3-3. 커뮤니티 유지 (연중)
- 팀 채팅방: 스토브리그 떡밥 토론 (유저 자발, 비용 0)
- 예측 게임: 주 1회 질문 자동 등록 (크론잡)
- 선수 게시판: 시즌 회고/기대글

### 3-4. 스프링캠프 (2~3월) — "복귀 트리거"
```
🔔 푸시 알림 시나리오:
Week 1: "⚾ 스프링캠프 시작! [팀명] 소식 보기"
Week 2: "🆕 [팀명] 신외인 첫 등판 — 어떤가요?"
Week 3: "📊 시범경기 시작! 오늘 14:00"
Week 4: "🏟️ 개막 7일 전! 순위 예측하고 포인트 받기"
```

## 4. 기술 구현

### 시즌 모드 스위치
```typescript
type SeasonMode = "regular" | "postseason" | "stoveLeague" | "springCamp" | "preseason";

function getCurrentMode(): SeasonMode {
  const month = new Date().getMonth() + 1;
  if (month >= 4 && month <= 9) return "regular";
  if (month === 10) return "postseason";
  if (month >= 11 || month === 1) return "stoveLeague";
  if (month === 2) return "springCamp";
  return "preseason";
}
```

홈 화면이 모드에 따라 자동 변환:
- **regular**: 오늘 경기 + 순위 + 예측
- **stoveLeague**: FA 뉴스 + 스토브리그 예측 + 투표
- **springCamp**: 캠프 뉴스 + 신외인 프로필 + 개막 카운트다운

### 구현 비용
| 항목 | 개발 | 운영 |
|------|------|------|
| 시즌 모드 스위치 | 2h | 0 |
| 뉴스 크롤러 키워드 변경 | 이미 있음 | 0 |
| 예측 문제 전환 | 1h | 주 10분 |
| Wrapped 카드 | 4h | 0 |
| 개막 카운트다운 | 30min | 0 |
| **합계** | **~8시간** | **주 10분** |

서버 비용: **$0** (Vercel + Supabase Free Tier)

## 5. 오프시즌 = 획득 기회

### 왜 오프시즌이 유저 획득에 좋은가
1. 경쟁 앱도 잠잠 → 노출 기회
2. FA 떡밥은 일반인도 관심 → 바이럴 소재
3. 시즌 전 설치 → 개막일 리텐션
4. Wrapped 공유 → 자연 바이럴

### 유저 획득 퍼널
```
[스토브리그 뉴스/예측] → [설치] → [Wrapped 공유] → [친구 설치]
        ↓                                ↓
   [개막 알림]                       [개막 알림]
        ↓                                ↓
   [시즌 활성유저]                   [시즌 활성유저]
```

## 8. 결론

> **"쉬되 죽지 않게, 운영하되 지치지 않게"**

- 순수 죽은 기간 = **2개월**(12~1월)뿐
- Prediction = **연중 콘텐츠 엔진** (시즌: 승부예측, 오프: FA/순위 예측)
- Wrapped = **한번 만들면 매년 자동 바이럴**
- 포인트/등급 연중 유지 = **이탈 방지 핵심**
- **오프시즌 운영 = $0 + 주 10분 + 8시간 초기 투자**
