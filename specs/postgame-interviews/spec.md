# 경기별 수훈선수 인터뷰 MVP

## 목표

종료 경기 상세에서 해당 경기에 고신뢰로 매핑된 수훈선수 인터뷰만 원본 YouTube 링크로 노출한다. 영상이 없거나 매핑이 애매하면 영역을 숨긴다.

## 확정 정책

- 탐색 시작: 경기 종료 30분 후
- 탐색 간격:
  - 종료 30분~3시간: 15분
  - 3~8시간: 30분
  - 8~24시간: 1시간
- 탐색 종료: 경기 종료 24시간
- 소스 우선순위: 공식 중계사 YouTube → 구단 공식 YouTube
- 다운로드·재업로드 없이 원본 링크와 YouTube 썸네일만 사용
- 자동 매핑 필수 조건:
  - 공식 채널 allowlist
  - 제목에 `인터뷰`, `엔터뷰`, `수훈선수` 중 하나
  - 제목에 경기 날짜
  - 제목의 선수명이 승리팀 당일 box score에 존재
  - 후보 경기가 정확히 1개
- 더블헤더·복수 경기 후보·무승부·box score 결측은 미노출

## 비목표

- 비공식 채널 수집
- 저신뢰 관리자 검수 UI
- 영상 다운로드, 재인코딩, 재업로드
- 24시간이 지난 인터뷰의 아카이브 보강

## 성공 기준

- 정책 함수가 경계값(30분, 3시간, 8시간, 24시간)을 정확히 지킨다.
- 같은 날짜·같은 선수의 더블헤더 후보는 자동 매핑하지 않는다.
- DB에 저장된 영상이 있는 종료 경기에서만 카드가 보인다.
- 크론 재실행 시 `(game_id, video_id)` 기준으로 중복 저장되지 않는다.
