# 크보 에브리데이 — 서비스 1 Pager

> KBO 팬을 위한 올인원 커뮤니티 플랫폼

## 🎯 Problem
- KBO 관중 **1,000만 시대**, 그러나 팬 전용 앱 없음
- 네이버 스포츠는 뉴스/중계만 → 팬 커뮤니티·개인화 부재
- 20대 여성 팬 급증, "선수 덕질" 수요 폭발 → 받쳐주는 플랫폼 없음
- 기존 커뮤니티(에펨코리아, 카페)는 야구 특화 UX 없음

## 💡 Solution
**크보 에브리데이** — 내 팀·내 선수 중심의 개인화된 KBO 팬 경험

## ✨ 핵심 기능

| 카테고리 | 기능 | 상태 |
|---------|------|------|
| ⚾ 경기 | 실시간 스코어, 시범경기/정규시즌 일정, AI 경기 분석 | ✅ Live |
| 📊 데이터 | 팀 순위, 타자/투수 스탯, 세이버메트릭스, 능력치 레이더 차트 | ✅ Live |
| 👤 선수 | 683명 프로필(bio/career/TMI), 30종 특성 뱃지, 선수별 뉴스 | ✅ Live |
| 🔮 예측 | 일일/시즌 승부예측, 리더보드, 공유 카드 | ✅ Live |
| 💬 커뮤니티 | 선수별 게시판, 직찍 갤러리, 실시간 채팅, 쪽지(DM) | ✅ Live |
| 📰 뉴스 | 내 팀/선수 맞춤 뉴스, 뉴스 캐러셀 | ✅ Live |
| 🎬 영상 | 팀별 하이라이트, 공식 영상/숏츠, 풀스크린 릴 뷰어 | ✅ Live |
| 🏟️ 구장 | 9개 구장 가이드(맛집/좌석/리뷰), 티켓 양도 | ✅ Live |
| 📚 입문 | 야구 튜토리얼 5장 33강, 선수 응원가 | ✅ Live |
| 🏆 뱃지 | 49종 활동 뱃지 + 30종 특성 뱃지, 초대 시스템, 레벨/등급 | ✅ Live |

## 🏗️ 기술 스택
- **Frontend**: Next.js 16 + TypeScript + Tailwind (PWA)
- **Backend**: Supabase (Auth, DB, Realtime, Storage) — 서울 리전
- **Data**: KBO 공식 API + Naver News API + YouTube Data API
- **Hosting**: Vercel Pro
- **AI**: 전 개발/운영 과정에 AI 에이전트 활용 (OpenClaw)

## 📈 비즈니스 모델
| Phase | 조건 | 수익 |
|-------|------|------|
| 1 | DAU < 1,000 | 무료, 광고 없음 |
| 2 | DAU 1,000+ | 인앱 광고 (구장 맛집 파트너십) |
| 3 | DAU 10,000+ | 프리미엄 구독 (고급 분석, 광고 제거) |
| Exit | DAU 50,000+ | KBO/스포츠 기업 매각 |

## 🚀 경쟁 우위
1. **AI-native 원맨 운영**: 인건비 0원, 개발/운영 전부 AI 에이전트
2. **683명 전 선수 프로필**: "이 선수에 대해 이렇게까지?" 수준의 데이터
3. **개인화**: 내 팀 + 최애 선수 기반 뉴스/영상/피드 커스텀
4. **니치 > 슈퍼앱**: 네이버 스포츠가 못 하는 팬 덕질 경험
5. **번레이트 극소**: 서버비 월 ~$20, 투자금 100% 마케팅 투입 가능
