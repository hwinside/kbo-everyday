# 승부예측 & 게이미피케이션 — Spec

## 데이터 모델

### predictions
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | bigserial (PK) | |
| user_id | uuid (FK) | |
| game_id | varchar(20) (FK) | |
| predicted_team_id | int (FK) | 예측한 승리팀 |
| is_correct | boolean (nullable) | null=미정산, true/false |
| points_earned | int | 획득 포인트 |
| created_at | timestamptz | |
| UNIQUE: (user_id, game_id) | | 경기당 1회 예측 |

### prediction_summary (경기별 집계)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| game_id | varchar(20) (PK) | |
| home_count | int | 홈팀 예측 수 |
| away_count | int | 원정팀 예측 수 |
| total_count | int | 전체 참여자 |

### user_streaks
| 컬럼 | 타입 | 설명 |
|------|------|------|
| user_id | uuid (PK) | |
| current_streak | int | 현재 연속 적중 |
| max_streak | int | 시즌 최고 연속 적중 |
| total_predictions | int | 총 예측 수 |
| total_correct | int | 총 적중 수 |
| updated_at | timestamptz | |

## 포인트 시스템

### 적중 포인트
| 조건 | 포인트 |
|------|--------|
| 기본 적중 | +10 |
| 3연속 적중 | +5 보너스 |
| 5연속 적중 | +15 보너스 |
| 10연속 적중 | +50 보너스 |
| 업셋 적중 (30% 미만 예측 성공) | ×2 배수 |
| 오답 | 0 (감점 없음) |

### 레벨 시스템
| 레벨 | 칭호 | 필요 포인트 | 뱃지 |
|------|------|-------------|------|
| 1 | 루키 | 0 | 🟤 |
| 5 | 레귤러 | 200 | 🔵 |
| 10 | 올스타 | 500 | 🟣 |
| 15 | 골드글러브 | 1,000 | 🟡 |
| 20 | MVP | 2,000 | 🔴 |
| 25 | 사이영 | 3,500 | 💎 |
| 30 | 명예의전당 | 5,000 | 👑 |

### 정산 로직
```
경기 종료 (status='final')
  → 승리팀 확인
  → predictions WHERE game_id = X 전체 조회
  → is_correct 업데이트
  → 포인트 계산 (기본 + 연속 보너스 + 업셋 보너스)
  → users.points += earned
  → user_streaks 업데이트
  → 레벨 체크 → 레벨업 시 알림
```

## UI

### 승부예측 화면 (경기 전)
```
┌─────────────────────────┐
│ 오늘의 승부예측           │
├─────────────────────────┤
│ ┌─────────────────────┐ │
│ │  LG  vs  두산       │ │
│ │  18:30 잠실          │ │
│ │                     │ │
│ │ [LG 승리]  [두산 승리]│ │
│ │  63%        37%     │ │
│ │  ███████░░░░        │ │
│ │  참여 1,234명       │ │
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
│ │  SSG vs  한화       │ │
│ │  ...                │ │
│ └─────────────────────┘ │
│ ...                     │
└─────────────────────────┘
```
- 팀 선택 시 팀 컬러로 버튼 하이라이트 + 햅틱 피드백
- 경기 시작 후 예측 마감 (버튼 비활성화)
- 비율 바: 양팀 컬러 그라데이션

### 승부예측 결과 (경기 후)
```
┌─────────────────────────┐
│ ✅ 적중! LG 5:3 두산     │
│ +10 포인트 (3연속 +5)    │
│ 🔥 현재 3연속 적중!      │
│                         │
│ ❌ 오답 SSG 2:4 한화     │
│ 연속 적중 초기화          │
└─────────────────────────┘
```
- 적중: 금색 배경 + 축하 애니메이션 (confetti)
- 연속 적중: 불꽃 이펙트

### 리더보드
```
┌─────────────────────────┐
│ 🏆 예측왕 랭킹           │
│ [전체] [팀별] [주간]     │
├─────────────────────────┤
│ 1  👑 야구마스터  5,230p │
│ 2  💎 크보덕후    4,891p │
│ 3  🔴 엘지골드    3,456p │
│ ...                     │
│ 48 🔵 나          892p  │ ← 내 순위 하이라이트
└─────────────────────────┘
```
- 상위 3명: 금/은/동 효과
- 내 순위는 항상 표시 (스크롤 위치와 무관)
- 시즌 종료 시 리셋 + 명예의전당 기록

### 프로필 뱃지 (게시판 연동)
```
[LG] 👑 야구마스터 Lv.30
```
- 닉네임 옆에 레벨 뱃지 + 칭호 표시
- 게시판/채팅에서 자동 표시
- 높은 레벨 = 예측에 대한 신뢰도

## 인덱스
- predictions: (game_id, user_id) UNIQUE
- predictions: (user_id, created_at DESC)
- user_streaks: (total_correct DESC) — 랭킹용
- users: (points DESC) — 리더보드
