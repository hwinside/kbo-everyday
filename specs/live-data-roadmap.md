## 현재 데이터 소스

- **KBO 공식 API**: `koreabaseball.com/ws/Main.asmx/GetKboGameList`

## 핵심 리스크

1. **데이터 갱신 주기**: 티빙/네이버(1~3초) vs 우리(폴링 15~30초). UX 차이 있으나 팬앱으로서 충분
2. **수비 배치 실시간 교체**: 라인업 공개 시 포지션 포함 여부 확인 필요. 경기 중 교체 반영은 문자중계 크롤링
3. **KBO API 안정성**: 공식 API가 아닌 비공식 엔드포인트 → 시즌 중 변경 가능성

## 기술 메모

- `game-live` API route (`src/app/api/game-live/route.ts`)에서 이미 BSO + 주자 이름 파싱 중
- `LiveGameData` 타입에 `runner1bName/2bName/3bName` 추가 완료
- Vercel 서버리스에서 Playwright 사용 불가 → Mac mini cron으로 크롤링 → static JSON 업데이트 패턴 사용
