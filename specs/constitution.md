# 크보 에브리데이 — Constitution (Final)
> 확정일: 2026-02-28

## 🎯 프로젝트 목적
크보(KBO) 전 구단 팬을 위한 커뮤니티 중심 플랫폼.
온라인에 사실상 없는 **"선수별 전용 커뮤니티"**를 최초로 제공하고,
경기별 실시간 게시판에서 팬들이 모여 이야기하고 응원하고 (싸우고 ㅋㅋ) 할 수 있는 공간.

---

## 💰 비즈니스 모델
- **무료 서비스 + 광고 수익**
- 멀티 광고 네트워크: AdSense + AdMob + 카카오 애드핏
- SSP 미디에이션: AdMob Mediation으로 여러 네트워크 경쟁 입찰 → 수익 최적화
- 향후: 프리미엄 기능 (광고 제거, AI 분석 등) 구독 모델 검토

---

## 🏗️ 기술 스택

### Frontend
- **Next.js 15** (App Router) — 웹앱/PWA/SEO
- **Capacitor** — iOS/Android 네이티브 앱 래핑 (웹 코드 99% 재사용)
- **Tailwind CSS** — 모바일 퍼스트 반응형 UI
- **Framer Motion** — 페이지 전환, 카드 인터랙션, 마이크로 인터랙션
- **GSAP** — 스크롤 기반 애니메이션, 복잡한 시퀀스

### Backend
- **Supabase** (PostgreSQL + Auth + Realtime + Storage)
  - 실시간 게시판 → Supabase Realtime (WebSocket)
  - 유저 인증 → Supabase Auth (카카오, 구글, 애플 소셜 로그인)
  - 이미지 업로드 → Supabase Storage
  - 무료 티어 → Pro($25/월) → 트래픽에 따라 스케일업

### 시각화
- **Nivo** — 레이더 차트, 인포그래픽 (예쁜 비주얼)
- **Recharts** — 추이 라인 차트, 시계열 데이터 (가볍고 실용적)

### 데이터
- KBO 경기 일정/스코어: 공개 데이터 크롤링 (네이버 스포츠, KBO 공식)
- 선수 스탯: 공개 소스 참조
- 선수 사진/팀 로고: 무료+광고 모델, 팬사이트 관행 적용
- YouTube Data API: 구단 공식 영상 (무료 할당량 10,000/일)

### 광고
- **Google AdSense** — 웹
- **Google AdMob** — 앱 내 광고 + Mediation SSP
- **카카오 애드핏** — 한국 트래픽 최적화

### 배포
- **Vercel** — 웹앱 호스팅 (자동 스케일링)
- **Apple App Store / Google Play** — 네이티브 앱
- **Cloudflare** — 도메인/CDN

## 🎮 핵심 기능

### P0 — MVP

#### 1. 선수별 게시판 ⭐ (온라인 최초)
- KBO 10개 구단 × 전 선수 = 선수별 전용 게시판
- 글 작성, 댓글, 좋아요, 신고
- 선수 프로필 카드 (사진, 등번호, 기본 스탯)

#### 2. 경기별 실시간 게시판 ⭐
- 오늘 경기 목록 → 경기 선택 → 실시간 채팅형 게시판
- 양 팀 팬이 같은 공간에서 대화
- 팀 플레어(flair) 표시 — "LG 팬", "두산 팬" 등

#### 3. 실시간 경기 트래커
- **비주얼 다이아몬드**: 주자 위치 실시간 점등/소등 애니메이션
- **스코어보드**: 이닝별 점수, 볼-스트라이크-아웃 카운트, 현재 타자/투수
- **실시간 문자 중계**: 투구별/타석별 자동 업데이트 (5~10초 갱신)
- **📻 라디오 중계**: MBC/SBS 스포츠 라디오 인앱 스트리밍, 백그라운드 재생
- **통합 레이아웃:**
```
┌─────────────────────────┐
│ 📻 MBC 스포츠 ▶️ ━━━●── │ 라디오
│ LG 3:2 두산  5회말       │ 스코어
│ ◇◆◇  B2 S1 O1          │ 다이아몬드
├─────────────────────────┤
│ ▸ 오스틴 좌전안타 (1타점) │ 문자 중계
├─────────────────────────┤
│ 💬 실시간 채팅            │ 팬 채팅
└─────────────────────────┘
```

#### 4. 유저 시스템
- 소셜 로그인 (카카오, 구글, 애플)
- 마이팀 설정 → 팀 플레어 자동 표시
- 닉네임, 프로필 이미지, 활동 기록

#### 5. 구단별 게시판
- 10개 구단 각각의 자유 게시판
- 인기글 / 최신글 정렬

#### 6. 스탯 인포그래픽
- **선수 스탯 카드**: 투수(ERA, WHIP, K/9) / 타자(타율, OPS, HR) — Nivo 레이더 차트
- **최근 추이**: 최근 10/30경기 퍼포먼스 — Recharts 라인 차트
- **팀 스탯 대시보드**: 순위, 최근 10경기 폼, 리그 평균 대비 비교
- **팀 간 비교**: 두 팀 선택 → 나란히 비교
- 카드형 UI, 스와이프로 선수 간 비교

#### 7. 뉴스 & 콘텐츠 피드
- 팀별 최신 뉴스 자동 수집 (헤드라인 + 썸네일 + 원문 링크)
- 구단 공식 유튜브 영상 임베드 (인앱 재생)
- 탭: 뉴스 | 영상 | 전체
- 마이팀 우선 표시, 30분 간격 자동 갱신

#### 8. 승부예측 & 게이미피케이션
- **승부예측**: 경기별 승/패 예측, 비율 실시간 표시, 자동 정산
- **포인트**: 적중 기본 + 연속적중 보너스 + 업셋 보너스
- **레벨**: Lv.1 루키 → Lv.5 레귤러 → Lv.10 올스타 → Lv.20 MVP → Lv.30 명예의전당
- **리더보드**: 전체/팀별/주간 랭킹, 시즌 종료 시 명예의전당
- 게시판에서 레벨 뱃지 표시

### P1 — Phase 2
- 경기 일정 캘린더 (오늘/이번주/이번달)
- 실시간 스코어 (전 경기 한눈에)
- 순위표
- 알림 시스템 (내 팀 경기, 내 글 댓글, 푸시)

### P2 — Phase 3
- AI 분석 (경기 예측, 선수 비교)
- 시즌 단위 예측 (MVP, 홈런왕, 우승팀)
- 이닝별 세부 예측 (고급 모드)

## 🎨 디자인 & UX

### 디자인 철학
**Apple + 스포츠 = 프리미엄 팬 경험**
"이게 무료 앱이라고?" 가 목표.

### 비주얼
- **글래스모피즘** — backdrop-blur, 반투명 카드
- **다이나믹 팀 컬러** — 팀 페이지 진입 시 배경 그라데이션 전환
- **다크 모드 기본** + 라이트 모드 (OLED 최적화)
- **SF Pro / Pretendard** — 프리미엄 타이포그래피
- **커스텀 야구 아이콘셋**

### 모션
- 60fps 스프링 물리 기반 (Apple 느낌)
- 득점 시 화면 이펙트 (파티클, 팀 컬러 플래시)
- Shared Element Transition (선수 카드 → 상세 페이지)

### 인터랙션
- 제스처 네비게이션 (스와이프, 풀 투 리프레시)
- 햅틱 피드백 (좋아요, 투표 시)
- Skeleton UI + Optimistic UI

### 퍼포먼스
- React Server Components + Streaming SSR
- Virtual Scrolling (TanStack Virtual)
- Image Optimization (AVIF/WebP + blur placeholder)
- Code Splitting + Service Worker
- **Core Web Vitals: LCP < 1.5s, FID < 50ms, CLS < 0.05**

### 최신 CSS/브라우저 기술
- View Transitions API — 네이티브급 페이지 전환
- Scroll-driven Animations — CSS만으로 60fps
- Container Queries — 컴포넌트 단위 반응형
- CSS :has() — 상태 기반 스타일링
- Popover API — 네이티브 팝오버

## 수익화 전략 (Monetization)

### Phase 1 — 무료 + 광고 (런칭~)
- 완전 무료 서비스
- AdMob 배너 + 네이티브 광고 (피드 사이)
- 카카오 애드핏 (AdMob Mediation)
- 구단 로고/선수 사진 → 자체 제작 아이콘/팬아트로 대체 (상표권/초상권 리스크 회피)

### Phase 2 — 프리미엄 구독 (MAU 10만+)
- **과금 대상: 커뮤니티 경험** (데이터 X)
  - 광고 제거
  - 프리미엄 뱃지/프로필 커스텀
  - 승부예측 보너스 포인트
  - 커뮤니티 특수 이모지/스티커
- 가격: ₩1,900~3,900/월
- **안전**: KBO 데이터/초상권과 무관한 기능에만 과금

### Phase 3 — 공식 파트너십 (MAU 100만+)
- KBO/구단 정식 라이선스 계약
- 공식 데이터 + 로고 사용 허가
- 구단 스폰서십 (공식 팬 커뮤니티 파트너)
- 티켓/굿즈 커머스 연동 (수수료)

| 항목 | 리스크 | 대응 |
