## 🏠 1. 홈 (경기 일정) — `ScreenGameSchedule`

### 🔴 P0: 날짜 스트립 — *오늘이 좌측이 아니라 중앙*
```
22(목)·23(금)·24(토오늘)·25·26·27·28
```
- 과거 2일 + 오늘 + 미래 4일 구조
- *문제*: 유저가 늘 "오늘 경기"를 보러 오는데 오늘이 *정중앙*이 아닌 *중앙보다 좌측*(3/7 위치)
- 대안 A: 오늘을 좌측 끝(1/7) + 미래 6일
- 대안 B: 오늘을 정중앙(4/7, 좌3 우3) — *권장*
- V1 현재 동작 확인 필요: 유저가 과거 날짜를 실제로 탭하는 빈도?

### 🟡 P1: "경기 일정" 타이틀이 *홈 탭*에 맞는가
- 하단 TabBar는 `games` 탭이 활성화돼 있는데 이 화면은 *사실상 홈화면*
- 그런데 타이틀이 "경기 일정"
- 질문: V1의 홈 구성과 비교 시 이 화면이 *홈 = 경기 일정*인 건가, 아니면 별도 탭인가?
- 현재 구조상 `home` 탭 활성화 화면은 **없음**. 홈이 곧 경기 일정 = *TabBar에 home 탭 불필요* 가능성
- → **Plan §1 파일 구조 재검토 필요**: `src/app/(v2)/page.tsx`가 스케줄이라면 TabBar `home` 제거하고 `games`를 첫 탭으로

### 🟢 OK: 경기 카드 구성
- 라이브 LIVE 뱃지 + 이닝 표시
- VS 레이아웃 명확
- 베뉴 표시
- 승팀 컬러 강조 — 팀 accent

### 🟡 P2: 날짜 스트립 "과거"를 연한 opacity로 표시 — *클릭 가능 여부 불명*
- 과거 경기도 결과 조회해야 하는데 `opacity: 0.45`만 적용
- 실제 클릭 가능한지 시각적으로 모호
- 권장: 과거도 클릭 가능하면 opacity 0.7 + 배경 약간 변경 / 불가능하면 완전 비활성 스타일 (cursor: not-allowed)

- 권장:
  - 내 팀 경기를 *최상단 고정* + 히어로 카드 사이즈로 확대
  - 나머지 경기는 컴팩트 리스트
